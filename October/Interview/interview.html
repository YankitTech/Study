*** Interview Questions ***

  • why is Playwright faster? Because it directly interacts with the browser element, unlike selenium which use web-driver. It also has built in auto waiting.
  • How to setup Playwright project 1. install node 2. npm init Playwright@latest 3. npx Playwright install - to download browser binaries needed for execution.
  • How does Playwright communicate with the browser? Playwright communicates directly with the browser using its native automation protocol. for chromium it used the chrome devtools protocol and for firefox and webkit use their own browser protocols. Therefore it doesnot need a separate webdriver. this reduces the execution time, gives better performance and stable automation flow.
  • what is autowaiting? and if Playwright have autowaiting then why we use async and await? Auto-waiting means Playwright waits for an element to be ready before it acts on it, Why you still need async and await They solve a different problem: Auto-waiting is Playwright waiting for the browser page to be ready. await is JavaScript waiting for Playwright’s function call to finish. Every Playwright action talks to a browser, which takes time, so it returns a Promise. Without await, your code doesn’t wait for that Promise and moves straight to the next line. The auto-waiting happens inside the call you are awaiting.
